# Git 工作台

在 DeepSeek Harness 左侧栏添加“Git 工作台”入口，并打开独立主页面。

- 未配置账户时显示新增引导。
- 可新增 GitHub、GitLab、Gitee 或 Codeup 账户，并填写用户名和访问令牌。
- 已配置账户可从顶部下拉框切换；下拉项同时标明托管平台和用户名。
- 可编辑账户的托管平台和用户名；留空令牌表示保留原令牌，填写则替换本机令牌。
- 删除账户需二次确认，会同时移除账户元数据、当前选择和凭据存储中的令牌。
- 账户元数据与当前选择通过插件的本机配置持久化。
- 访问令牌只写入 DSH 凭据存储，不进入普通账户配置，也不会被页面读取或回显。
- 选择 Codeup 账户后，可查看“我负责或参与”的云效项目协作需求、任务和缺陷。
- 支持组织与项目筛选；列表显示标题、编号、类型、状态、项目、负责人和更新时间。
- 点击工作项可读取完整描述、参与人、创建人和自定义字段，并提供「在云效中打开」直达链接（该链接依据云效 Web 路由构造，非 API 返回字段）。
- “负责”和“参与”关系由 Host 按用户 ID 在结果中本地判定；项目和工作项均逐页完整读取。仅当达到极端的分页或数量安全上限时，页面才提示结果可能不完整。

本插件只读取云效数据，不修改工作项，不执行 Git 命令，也不添加自动化或代理工具。令牌仅在 Host 端用于请求 `https://openapi-rdc.aliyuncs.com`；浏览器 RPC 只传账户 ID 和筛选条件。卸载会移除此插件的左侧入口和主页面，不影响其他面板。
