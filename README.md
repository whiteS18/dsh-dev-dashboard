# Git 工作台

在 DeepSeek Harness 左侧栏添加“Git 工作台”入口，并打开独立主页面。

- 未配置账户时通过“管理账户”引导新增配置；已配置账户时在工具栏使用同一个“管理账户”入口。
- 可新增 GitHub、GitLab、Gitee 或 Codeup 账户，并填写用户名和访问令牌。
- 已配置账户可从顶部下拉框切换；下拉项同时标明托管平台和用户名。
- 账户下拉框与「管理账户」按钮之间提供「查看任务 / 查看仓库」下拉切换：
  - **查看任务**：查看当前账户的 Codeup 工作项或 GitHub Issues。
  - **查看仓库**：查看当前账户下的 Git 仓库列表与详情（支持组织/所有者筛选、搜索和分页）；选中仓库后可直接点击「克隆到本地」克隆至 `~/project`，克隆完成后弹出提示“是否创建该仓库的工作区？”，选择「是」即自动创建并打开工作区，选择「否」则仅保留本地克隆。
- 可编辑账户的托管平台和用户名；留空令牌表示保留原令牌，填写则替换本机令牌。
- 删除账户需二次确认，会同时移除账户元数据、当前选择和凭据存储中的令牌。
- 账户元数据与当前选择通过插件的本机配置持久化。
- 访问令牌只写入 DSH 凭据存储，不进入普通账户配置，也不会被页面读取或回显。
- 选择 Codeup 账户后，可查看“我负责或参与”的云效项目协作需求、任务和缺陷。
- 选择 GitHub 账户后，可查看该账户可访问仓库中的 GitHub Issues（自动排除 Pull Request），支持按所有者（个人/组织）与仓库筛选、Markdown 描述渲染、直达 GitHub 链接，以及点击“开始/继续”克隆对应仓库并打开工作区。
- 支持组织/所有者与项目/仓库筛选；列表显示标题、编号、类型、状态、项目/仓库、负责人和更新时间。
- 点击工作项/Issue 可读取完整描述、参与人、创建人、标签和扩展字段，并提供在平台中打开的直达链接。
- Codeup 的“负责”和“参与”关系由 Host 按用户 ID 在结果中本地判定；项目和工作项均逐页完整读取。仅当达到极端的分页或数量安全上限时，页面才提示结果可能不完整。

令牌仅在 Host 端用于请求 `https://openapi-rdc.aliyuncs.com` 或 `https://api.github.com` 以及按需克隆对应仓库；浏览器 RPC 只传账户 ID 和筛选条件。卸载会移除此插件的左侧入口和主页面，不影响其他面板。
